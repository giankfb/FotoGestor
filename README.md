# FotoGestor — V15

## Relatórios simplificados

Esta versão reorganiza a área de Relatórios em um formato de listagem, pensado para consulta e impressão.

### Tipos de relatório
- Agenda
- Datas disponíveis
- Contas a receber
- Contas a pagar
- Caixa

### Recursos
- Escolha do relatório na própria tela de Relatórios.
- Filtro por período (De/Até).
- Filtro por cliente quando aplicável.
- Disponibilidade com seleção dos dias da semana; sexta e sábado vêm selecionados.
- Lista simples, sem cards de resumo, para facilitar impressão.
- Cabeçalho de impressão com marca FotoGestor.
- Botão Imprimir / PDF.
- Botão para copiar datas disponíveis para WhatsApp.
- Eventos cancelados não bloqueiam datas na disponibilidade.

### Publicação
O backend Google Apps Script permanece o mesmo desta base. Para esta alteração, substitua os arquivos do frontend e publique normalmente no seu hospedador.
